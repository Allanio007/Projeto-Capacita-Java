# Projeto 1 - Curso Java

Repositorio de entrega do Projeto 1.

## Conteudo

- `taskmanager-console/`: implementacao do projeto Java (console).
- `arquitetura-roteador.md`: descricao da atividade e orientacoes de entrega.

## Como rodar o projeto

Entre na pasta do projeto e execute:

```bash
cd taskmanager-console
mvn clean test
mvn exec:java
```

## Requisitos

- Java 17+
- Maven 3.8+
